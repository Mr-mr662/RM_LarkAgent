# Personal Knowledge Base

Put personal or team knowledge files here. The assistant can search `.md` and `.txt` files in this directory.

Examples:

- FAQ
- team rules
- project notes
- meeting notes
- operation procedures

After changing files, ask the assistant:

```text
/run 重新加载知识库
/run 搜索知识库 报名规则
```

Do not put secrets, API keys, passwords, or private cookies in this directory.
